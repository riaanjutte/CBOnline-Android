# CB Online Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-page, always-dark landing site for CB Online in `site/`, published to GitHub Pages by a workflow, with a download button that follows the latest GitHub release.

**Architecture:** Hand-written static files (HTML, CSS, two ES modules) with no build step. `release.js` turns GitHub's latest-release JSON into a link and a release line; `main.js` applies it to the page and falls back silently. Node's built-in test runner covers both modules and a contract test for `index.html`; a GitHub Actions workflow runs those tests and publishes `site/` only.

**Tech Stack:** HTML, CSS, ES modules; Node 24 (`node --test`, no npm packages); ImageMagick 7 (WebP/JPEG assets); GitHub Actions Pages actions.

**Spec:** `docs/superpowers/specs/2026-10-04-website-design.md`

## Global Constraints

- Site URL `https://riaanjutte.github.io/CBOnline-Android/`; every local path in the site is relative (never starts with `/`).
- No npm packages, no build step, no analytics, cookies, trackers or third-party fonts/scripts/styles. The only outside request is `https://api.github.com/repos/riaanjutte/CBOnline-Android/releases/latest`.
- Colours: background `#161817`, panel `#1C1F1E` at 94 %, border white at 11 %, text `#F3F5F2`, muted `#AEB7B3`, red `#D2352A`, amber `#D4AA5D`, sky `#7BC4EE`.
- Oswald (self-hosted `assets/oswald.ttf`) for headline, labels, section headings, buttons; system UI stack for body.
- Exact copy: label **For Android**; headline **Who's flying on Combat Box?**; button **Download for Android**; fallback line **Latest version on GitHub · Android 8.0 or newer**; release line **Version {version} · {size} MB · Android 8.0 or newer**; title **CB Online: who's flying on Combat Box**.
- The site makes no claim the README doesn't; install help and FAQ wording comes from `README.md`.
- Breakpoints: top-bar links from 600 px; hero screenshot beside the text from 760 px; feature grid 3 columns from 900 px, 2 from 600 px, 1 below.
- Commits by the repo's configured author (noreply address) and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Pushing, merging and any GitHub setting change need the maintainer's explicit OK.

## Review Focus

- **Narrow phones (320 px) and long unbreakable text** (`CBOnline-<version>.apk`, `campaign-data.combatbox.net`): must wrap, never scroll sideways. Pinned in Task 4's browser checks at 320 px.
- **Anchor jumps under the sticky top bar:** the section heading must land below the bar, not under it. Pinned in Task 4 (`scroll-margin-top`, checked after clicking each nav link).
- **Large text settings (Android font scale up to 200 %):** panels, button and nav must still fit without sideways scrolling. Pinned in Task 4 (root font size 200 % check).
- **Map image slow or missing:** hero text must stay legible on the plain background colour. Pinned in Task 4 (hero has `background-color` under the image; checked with the image URL broken).
- **Absolute paths breaking under `/CBOnline-Android/`:** pinned in Task 4's page contract test (no local `src`/`href` starting with `/`).

### Task 1: Release logic (`release.js`)

**Files:**
- Create: `site/release.js`
- Test: `tests/site/release.test.mjs`

**Interfaces:**
- Produces: `export const FALLBACK_LINE: string` (`"Latest version on GitHub · Android 8.0 or newer"`); `export function pickApk(release: unknown): { version: string, url: string, sizeLabel: string } | null`; `export function releaseLine(result: ReturnType<typeof pickApk>): string`.

- [ ] **Step 1: Write the failing tests** in `tests/site/release.test.mjs` (`node:test` + `node:assert/strict`, importing `../../site/release.js`). A helper `rel(overrides)` builds `{ tag_name: "v1.0.0", assets: [{ name: "CBOnline-1.0.0.apk", size: 2321394, browser_download_url: "https://github.com/riaanjutte/CBOnline-Android/releases/download/v1.0.0/CBOnline-1.0.0.apk" }] }`.

```js
test("normal release", () => assert.deepEqual(pickApk(rel()), { version: "1.0.0", url: APK_URL, sizeLabel: "2.3" }));
test("tag without v", () => assert.equal(pickApk(rel({ tag_name: "1.2.3" })).version, "1.2.3"));
test("tag with capital V", () => assert.equal(pickApk(rel({ tag_name: "V2.0.0" })).version, "2.0.0"));
test("missing or empty tag", () => { assert.equal(pickApk(rel({ tag_name: undefined })), null); assert.equal(pickApk(rel({ tag_name: "" })), null); });
test("no apk asset", () => assert.equal(pickApk(rel({ assets: [{ name: "notes.txt", size: 10, browser_download_url: "u" }] })), null));
test("empty or missing assets", () => { assert.equal(pickApk(rel({ assets: [] })), null); assert.equal(pickApk({ tag_name: "v1.0.0" }), null); });
test("apk not first, capitals accepted", () => assert.equal(pickApk(rel({ assets: [{ name: "a.txt", size: 1, browser_download_url: "x" }, { name: "App.APK", size: 1000000, browser_download_url: "y" }] })).url, "y"));
test("apk without download url is skipped", () => assert.equal(pickApk(rel({ assets: [{ name: "a.apk", size: 1 }] })), null));
test("size labels", () => {
  const size = (n) => pickApk(rel({ assets: [{ name: "a.apk", size: n, browser_download_url: "u" }] }));
  assert.equal(size(2321394).sizeLabel, "2.3"); assert.equal(size(1000000).sizeLabel, "1.0"); assert.equal(size(40000).sizeLabel, "0.1");
  assert.equal(size(0), null); assert.equal(size(undefined), null); assert.equal(size("2321394"), null);
});
test("not a release", () => { for (const v of [null, undefined, "x", 42, []]) assert.equal(pickApk(v), null); });
test("release line", () => {
  assert.equal(releaseLine({ version: "1.0.0", url: "u", sizeLabel: "2.3" }), "Version 1.0.0 · 2.3 MB · Android 8.0 or newer");
  assert.equal(releaseLine(null), "Latest version on GitHub · Android 8.0 or newer");
  assert.equal(FALLBACK_LINE, releaseLine(null));
});
```

### Task 2: Download button wiring (`main.js`)

**Files:**
- Create: `site/main.js`
- Test: `tests/site/main.test.mjs`

**Interfaces:**
- Consumes: `pickApk`, `releaseLine` from `./release.js` (Task 1).
- Produces: `export const RELEASE_API = "https://api.github.com/repos/riaanjutte/CBOnline-Android/releases/latest"`; `export async function wireDownload(doc = document, fetchImpl = fetch, timeoutMs = 5000): Promise<boolean>` — finds `#download` (an `<a>`) and `#release-line`; on success sets `href` to the APK URL and `textContent` to `releaseLine(result)` and resolves `true`; on any failure changes nothing and resolves `false`. Never rejects, never logs. The module calls `wireDownload()` itself only when `typeof document !== "undefined"`. The page (Task 4) must use the ids `download` and `release-line`.

- [ ] **Step 1: Write the failing tests** in `tests/site/main.test.mjs`. A fake doc: `fakeDoc()` returns `{ els: { download: { href: FALLBACK_URL }, "release-line": { textContent: FALLBACK_LINE } }, getElementById(id) { return this.els[id] ?? null } }`. Fake fetch helpers: `ok(json)` → `async () => ({ ok: true, json: async () => json })`.

```js
test("success updates link and line", async () => {
  const d = fakeDoc(); assert.equal(await wireDownload(d, ok(release), 50), true);
  assert.equal(d.els.download.href, APK_URL); assert.equal(d.els["release-line"].textContent, "Version 1.0.0 · 2.3 MB · Android 8.0 or newer");
});
test("sends the GitHub accept header to the release API", async () => { /* capture (url, init): url === RELEASE_API, init.headers.Accept === "application/vnd.github+json", init.signal is an AbortSignal */ });
for (const [name, impl] of [
  ["network error", async () => { throw new TypeError("offline"); }],
  ["rate limited", async () => ({ ok: false, status: 403, json: async () => ({}) })],
  ["bad json", async () => ({ ok: true, json: async () => { throw new SyntaxError("x"); } })],
  ["no apk", ok({ tag_name: "v1.0.0", assets: [] })],
]) test(`${name} keeps the fallback`, async () => { const d = fakeDoc(); assert.equal(await wireDownload(d, impl, 50), false); assertFallback(d); });
test("timeout keeps the fallback", async () => { /* impl returns a promise that rejects only when init.signal aborts; timeoutMs 20; resolves false; fallback intact */ });
test("missing elements resolve false without fetching", async () => { /* doc whose getElementById returns null; fetch impl that fails the test if called */ });
```
